# 📊 Data Analytics Task 1 - Data Cleaning & Preprocessing

A practical **Data Analytics project focused on data cleaning, preprocessing, validation, and data quality analysis** using Python, Pandas, and Excel.

This project was completed as part of my **Data Analytics Internship at DecodeLabs**.

---

## 🎯 Project Objective

The main objective of this project is to transform a raw e-commerce dataset into a **clean, consistent, and analysis-ready dataset**.

The project focuses on identifying common data-quality issues such as:

* Duplicate records
* Missing values
* Incomplete coupon information
* Inconsistent data
* Data validation issues

The cleaned dataset is then validated to ensure that the preprocessing steps were applied correctly.

## 🔍 Key Tasks Performed

### 1. Dataset Inspection

The dataset was initially loaded and inspected to understand:

* Number of records
* Number of columns
* Column names
* Data structure
* Existing missing values

### 2. Duplicate Record Analysis

Duplicate rows were identified before cleaning.

The dataset was then processed to remove duplicate records and the results were compared before and after preprocessing.

### 3. Missing Value Analysis

Missing values were analyzed across the dataset to identify incomplete records.

Special attention was given to the **CouponCode** field.

The number of missing values was checked both before and after cleaning.

### 4. Data Cleaning

Data preprocessing techniques were applied to improve the overall quality and consistency of the dataset.

### 5. Data Validation

After cleaning, the dataset was rechecked to verify:

* Duplicate records
* Missing values
* Coupon code completeness
* Remaining missing cells
* Overall dataset consistency

### 6. Cleaning Report

A structured cleaning report was generated to compare the dataset **before and after preprocessing**.
